## Brand & Style

Quiet Studio is a clinical-luxury visual language for Only Good Things: civic content, editorial calm. It is not a healthcare or pharmacy product. Copy, features, and icons stay OGT (vecinos, feed, parking, animales, skills). Only the chrome changes.

The aesthetic is almost monochrome. Canvas is pure white. Chrome actions are ink. The only brand color is a deep navy-teal reserved for product photography, hero objects, and rare emphasis — never as a loud fill on every button. Emotion: precise, airy, trustworthy, unhurried. Extreme whitespace. No emerald, no terracotta, no mint chips, no emoji-as-icon.

Reference: studio product mock. It is a **mood board of principles**, not a layout to clone and not a catalog of objects to import.

Map each principle onto the real OGT object of that screen. Never force a bottle, price, scanner, or “health partner” composition onto civic flows.

| Principle in the demo | Apply it to OGT as |
|---|---|
| Hero object on white | Parking pin / radar, animal photo, skill person, points figure, neighbor deed — one object, lots of air |
| Circular icon buttons | GPS, ceder, buscar, campana, back, confirmar — 44px hairline circles; active = ink fill |
| Split CTA (pill + ink circle) | Comenzar, Ceder lugar, Publicar, Reportar — text pill + circular confirm |
| Search pill + circular action | Buscar vecinos, animales, skills, calle — gray pill; right action is scan/filter **only if that screen has that job** |
| Ink selected chips | Filtros reales: Todas / Parking / Mascotas / Skills / Ayuda — not medicine categories |
| Large ink numeral | Puntos, km, vecinos ayudados, plazas cedidas — never a fake `$` price |
| Floating dock | Feed / Mapa / Wallet (or the tabs that screen already has) |
| Two-up soft tiles | Acciones relacionadas, animales cercanos, skills sugeridas |
| Annotation arrows on a product | Optional callouts on a **map pin or deed photo**, not a supplement label layout |

## Colors

- **Primary (`#111213` / Ink):** Selected chips, filled circular CTAs, active dock item, primary text buttons. White label on ink.
- **Secondary (`#0D3D4D` / Harbor Navy):** Hero objects, product photography, rare emphasis, map pins. Not a second green.
- **Tertiary (`#5B6570` / Cool Slate):** Metadata, dismissible chips with ×, supporting glyphs.
- **Neutrals:**
  - Canvas: `#FFFFFF`
  - Soft wells (search, tiles, inactive cards): `#F4F5F7`
  - Hairline: `#E5E7EB`
  - Ink text: `#0A0A0B`
  - Muted body: `#6B7280` / `#8B919A`
  - Powder / decorative dust: `#C8CED4`

Do not use lush greens (`#059669`, `#10B981`, `#ECFDF5`) or terracotta (`#EA580C`, `#FFF7ED`) in new work.

## Typography

Headlines: **Plus Jakarta Sans** 700, tight tracking (`-0.02em` to `-0.03em`), 2–3 short lines, almost black. Body and chrome: **Inter**, 13–14px, muted gray. Key stats (puntos, plazas, km) render as large ink display figures, not colored badges and not currency.

## Layout & Spacing

Mobile-first, 390-wide frames. Side padding `20px`. Large vertical gaps between hero, title, and chrome. Do not pack cards edge-to-edge. Keep each screen’s information architecture (map stays a map, chat stays a thread, wallet stays a ledger). Quiet Studio changes chrome and density, not the job of the screen.

## Elevation & Depth

Almost flat. Cards and docks use a hairline `#E5E7EB` plus `0 8px 24px rgba(10,10,11,0.06)`. No green-tinted shadows. No heavy skeuomorphism. Hero photography sits on white with soft contact shadow only.

## Shapes

Pill-first (`roundedness: 3`):

- Search, filters, text CTAs, floating dock: `9999px`
- Icon buttons: perfect circles, 40–48px
- Media / product tiles: `1.5rem`–`2rem`
- Selected chip: ink fill, white label
- Unselected chip: white fill, 1px hairline, ink or slate label

## Components

### Buttons
- **Primary text CTA:** Full-width (or flex-grow) white pill, 1px hairline, ink label, height 52–56px. Optional trailing `>>` chevrons.
- **Circular confirm:** Solid ink circle 48–56px, white glyph. Sits to the right of the text pill (split CTA).
- **Icon-only (chrome, 44px):** Same language as the studio sample. Idle = white circle + `#E5E7EB` hairline + **ink `#111213` line glyph**. Active / confirm = **ink fill + white glyph**. Inactive dock = hairline circle + slate `#6B7280` glyph. Harbor navy `#0D3D4D` only on a map pin, never on every tab.
- **Product meanings stay the existing Stitch set** (feed, parking/search, pets, skills, puntos, GPS, parked, yield). For 44px chrome they are **line-art in this palette**, not the mint/terracotta 3D tiles (those stay as large allegories). No letter `P`, no heart, no house, no emoji, no green glow.
- Never a green pill. Never terracotta alert pills.

### Chips
- Selected: ink pill, white 13px medium label.
- Idle: white + hairline.
- Dismissible: same idle chip + trailing × in slate.
- No emoji prefixes. No mint/sunset tinted badges.

### Search
Full pill, `#F4F5F7` fill, no hard border, placeholder in `#9CA3AF`, optional circular action on the right (scan / filter) in ink.

### Cards
White or `#F4F5F7` well, `1.5rem` radius, hairline optional, generous padding. Hero is the screen’s real object (deed photo, animal, map, points). Related items: two-up soft tiles only when the screen already has a related list.

### Header
Avatar circle left. Two circular icon buttons right (alerts, menu). Title is editorial, not a colored wordmark bar. No green logo lockup in the header.

### Bottom dock
Floating white pill, ~72px from side edges, soft shadow. Three to five circular items. Selected item is a larger ink circle with white glyph. Unselected: outline circle, slate glyph. Home / grid / bag (or OGT equivalents: feed / map / wallet) — not a 5-tab green bar glued to the screen edge.

### Avatars
Circle, no green halo ring. Optional hairline.

## Icons

Only Stitch assets already in `design/stitch/` and `composeResources/drawable`. Do not invent Canvas glyphs, emoji, or Material as product icons. Map: parked / yield / search / logo / GPS / onboard.

## Do not

- Recolor OGT into a pharmacy catalog (no CoQ10, no “health partner” copy).
- Keep Lush Impact emerald / terracotta as the default chrome.
- Use emoji or letter-glyphs as tab icons.
- Fill the canvas with stacked colorful cards.
